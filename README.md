# Инвентарь — запуск в браузере без Mac

Этот репозиторий запускает приложение [RPiPiP-InventoryQR](https://github.com/dezshev/RPiPiP-InventoryQR)
в симуляторе iPhone на виртуальной машине macOS сервиса GitHub Actions и показывает экран симулятора
в обычном браузере (Windows, Linux, телефон). Касания, свайпы и ввод текста передаются в симулятор.

## Как запустить

1. Вкладка **Actions** → слева **«Запустить приложение в браузере»** → справа серая кнопка **Run workflow** → в окошке зелёная кнопка **Run workflow**.
2. На открывшейся странице запуска нажмите слева **remote** и подождите 5–7 минут.
3. Нажмите на шаг **«ССЫЛКА НА ПРИЛОЖЕНИЕ (нажмите сюда)»** и откройте ссылку `https://….trycloudflare.com`.
4. Введите пароль (значение секрета `VNC_PASSWORD`) и нажмите «Войти».

## Управление

- щелчок мышью — касание, перетаскивание — свайп (прокрутка списков);
- ввод текста: нажмите на поле в приложении и печатайте на клавиатуре компьютера (или используйте поле «Текст для ввода» + «Ввести»), кириллица поддерживается;
- «⌫», «Enter», «Домой», «Перезапустить приложение».

Сканер QR-кодов в симуляторе работает в режиме программного mock: выбирается снимок наклейки с QR-кодом.

Завершить сеанс досрочно — кнопка **Cancel workflow** на странице запуска.
